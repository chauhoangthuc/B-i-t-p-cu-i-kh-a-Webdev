# Rule 02: Stitch to Tailwind CSS Mapping Guide

- **Layout:** Map CSS Flexbox/Grid properties directly to Tailwind classes (`flex`, `grid`, `items-center`, `justify-between`, `gap-x`).
- **Colors & Typography:** Standardize color shades matching the project's design tokens (e.g., `bg-slate-50`, `text-primary-600`, `font-semibold`).
- **States:** Always include interactive utility classes for user feedback (`hover:`, `focus:`, `active:`, `disabled:`, `transition-all`).
